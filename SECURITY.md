# Security Policy

This repository builds and deploys surfaced.run (HTTPS) and gemini.surfaced.run (Gemini).

## Reporting a vulnerability

Email security@surfaced.run. Please include steps to reproduce and the URL or file involved.

I aim to acknowledge reports within 7 days. Please give me reasonable time to fix an issue before disclosing it publicly. I'm happy to credit you in the fix.

## Scope

- The static sites at https://surfaced.run/ and gemini://gemini.surfaced.run/
- The infrastructure defined in `infra/`
- The build and deploy tooling in this repository

Out of scope: Cloudflare and Google Cloud themselves (report those to the vendors), and volumetric denial of service.
